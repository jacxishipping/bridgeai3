## 2. Security & Architecture Review Findings (All P0/P1 Remediated)

### Pass 1 — Post-Wave-7 Diff Review (`caabc53`..`289a7df`)
1. **Python Full PC Access risk tiers (`src/ai_bridge/policy.py`):** elevated `write_pc_file` to Tier 4 (`HIGH_RISK`) and `list_directory` to Tier 3 (`SENSITIVE`); added all new Tier-3 desktop/window/UI/clipboard tools to `desktop_tools` in `decide()`.
2. **C# safe defaults & Full PC Access gates (`apps/windows-client/Models/AgentModels.cs`, `Services/NativeToolExecutor.cs`):** defaulted `AllowTier3 = false`, `MaxTierUnattended = 2`, `AllowFullPcFilesAndDrives = false`, `AllowShellAndPowerShell = false`; enforced Tier 4 on `WritePcFile` and Tier 3 on `ReadPcFile`/`ListDirectory`.
3. **Dashboard v3 View-Only (`apps/dashboard/src/views/DesktopView.tsx`):** gated keyboard dispatch ("Send Text", "Send Hotkey") on `controlArmed` and reset `controlArmed = false` on device switch.
4. **Windows launcher ACL (`deployment/windows/installer_gui.py`):** switched `_restrict_launcher_acl` to pure `.NET` `[System.IO.File]::GetAccessControl` / `SetAccessControl` so PowerShell 7 `PSModulePath` cannot break ACL hardening.
5. **v3 smoke check & restore drill scripts (`deployment/smoke_check.py`, `scripts/backup_drill.sh`):** aligned with v3 dashboard HTML shell and dynamic migration + audit-chain verification.

### Pass 2 — Independent Read-Only Reviewer Subagent Findings (Remediated)
1. **[P0] Local Tier-3 approval bypass & broken INSERT (`src/ai_bridge/control/ai_api.py`):** reset `_ap = None` when supplied `approval_id` is unapproved/expired/wrong-tool (returning HTTP 409 instead of falling through to `dispatch(..., is_admin=True)`), blocked workflow approvals from covering Tier-4 tools, and fixed the 8-column / 8-placeholder `INSERT INTO approvals`.
2. **[P0] Cross-tenant live desktop frame leak (`src/ai_bridge/control/routers/webrtc.py`):** scoped `GET /api/fleet/desktop/frames` by `resolve_request_tenant(...)`.
3. **[P0] Cross-tenant terminal session hijacking (`src/ai_bridge/control/routers/webrtc.py`):** enforced `sess.device_id == device_id` on `stream`, `input`, `resize`, and `delete` terminal endpoints.
4. **[P1] Additional cross-tenant authorization fixes:** added `_require_row_tenant` to `DELETE /api/approvals/{approval_id}` (`routers/tasks.py`), tenant scoping to `GET /api/fleet/broadcast/{batch_id}` (`routers/workflows.py`), tenant scoping to `_execute_workflow_step_sync` (`app.py`), and tenant + device-ownership checks to `GET /api/v1/sessions/{session_id}` and `WS /api/v1/ws/sessions/{session_id}` (`v1_routes.py`).
5. **[P1] CSRF spoofed-header bypass (`src/ai_bridge/control/csrf.py`):** checked `X-Session-Token` *before* `X-Admin-Token`/`X-Device-Token` exemptions so a dummy `X-Admin-Token` header alongside a session token cannot skip CSRF validation.
6. **[P1] Workflow approval Tier-4 escalation (`src/ai_bridge/control/task_service.py`):** restricted `execute_workflow`/`workflow` approvals to Tier ≤ 3; Tier-4 (`HIGH_RISK`) tools require a tool-specific approval.
7. **[P1] C# workspace confinement bypass when `AllowFullPcAccess=true` (`apps/windows-client/Services/NativeToolExecutor.cs`):** strictly confined `ListWorkspace`, `ReadWorkspaceFile`, `SearchWorkspace`, and `CreateWorkspaceFile` to `ConfineWorkspacePath` so Full PC Access can only be exercised via the Tier-3/4-gated `list_directory`/`read_pc_file`/`write_pc_file` tools.
8. **[P1] PostgreSQL drill live-DB overwrite & password-in-argv guards (`scripts/backup_restore.py`):** hard-refused `drill_postgres` when `source_dsn` and `restore_dsn` resolve to the same database, refused overwriting/dropping pre-existing databases (`allow_existing=False`), and passed credentials via `PGPASSWORD` env instead of plaintext in `argv`.
9. **[P1 — Live Deployment Finding] Agent revocation exit code (`agents/common/poller.py`):** `Poller.run_once()` now calls `_mark_terminal_auth()` when `/api/agent/tasks/next` raises `DeviceRevokedError`/`DeviceTokenExpiredError`, so all platform agents exit cleanly with code `2` instead of `0`.

### Documented Lower-Priority Residuals (Tracked for Release 2/3)
- `deployment/windows/installer_gui.py`: `run-agent.cmd` still holds the service launcher token on Windows (ACL-locked); migrating service launch to DPAPI-sealed `device.token` + eliminating plaintext cmd interpolation is scheduled for Release 2 agent resilience.
- `src/ai_bridge/control/supervisor.py` (`enqueue_role_task`) and direct `_queue_webrtc_task` inserts should be unified onto `task_service.create_task()` in Release 2/3 code health.
- `src/ai_bridge/updates.py`: add monotonic anti-rollback version floor and `https://`-only URL enforcement in Release 2 release engineering.
- `apps/windows-client/Services/NativeToolExecutor.cs`: tighten `AllowedCommands` to reject shell metacharacters and cap `File.ReadAllText` streaming reads before memory load.
