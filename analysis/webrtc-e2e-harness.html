This page is a viewer peer (the same role as the dashboard's LiveDesktopView): it creates a v1 session, waits for the agent-originated SDP offer, answers it, trickles ICE, opens the ticket-authenticated signalling WebSocket, and — only if a real agent posts an offer — negotiates a peer connection and counts decoded video frames. So if no agent is attached, the honest outcome is negotiation attempted + clean no-source handling, never a fabricated frame. The verdict reflects that: see the criteria table.
Secrets: the admin token and stream ticket are typed/pasted at runtime, used only in request headers / the WS URL, and are never written to the log or the results JSON.
